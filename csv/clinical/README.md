# Clinical / Healthcare — `csv`

> ⚠️ **SYNTHETIC DATA.** Every record in this repository is invented. No real people, patients, accounts, vehicles or students appear here. See [synthetic-data-guarantees.md](../../docs/synthetic-data-guarantees.md).

Hospitals, doctors, patients, appointments, diagnoses, prescriptions and laboratory results, coded with real ICD-10 and LOINC standards.

Comma-separated values -- the most widely supported tabular format. One file per table, UTF-8, no byte-order mark, `\n` line endings.
