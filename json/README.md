# `json` files

JSON arrays, pretty-printed and readable, plus `.ndjson` line-delimited versions of the larger tables for streaming.

## Topics

| Topic | What's in it |
|---|---|
| [`automobile/`](automobile/) | Vehicles with checksum-valid VINs and Spanish plates, their owners, dealership sales, workshop history and ITV inspection records. |
| [`clinical/`](clinical/) | Hospitals, doctors, patients, appointments, diagnoses, prescriptions and laboratory results, coded with real ICD-10 and LOINC standards. |
| [`education/`](education/) | Spanish schools, pupils, courses and gradebooks on the 0-10 scale, with attendance that genuinely correlates with achievement. |
| [`finance/`](finance/) | Spanish bank accounts with valid IBANs, cards, a ledger with true running balances, loans that really amortise, and daily market data. |
| [`supermarket/`](supermarket/) | Stores, a Spanish grocery catalogue with scannable EAN-13 barcodes, loyalty customers, and till transactions whose totals reconcile to the cent. |

_Deliberately malformed `_edge-cases/` files for this format are planned but not yet generated._
