# Finance / Banking — `json`

> ⚠️ **SYNTHETIC DATA.** Every record in this repository is invented. No real people, patients, accounts, vehicles or students appear here. See [synthetic-data-guarantees.md](../../docs/synthetic-data-guarantees.md).

Spanish bank accounts with valid IBANs, cards, a ledger with true running balances, loans that really amortise, and daily market data.

JSON arrays, pretty-printed and readable, plus `.ndjson` line-delimited versions of the larger tables for streaming.
